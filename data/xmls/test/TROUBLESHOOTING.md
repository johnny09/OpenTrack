# 抖动问题排查指南

## 问题：圆柱体在目标位置0时持续抖动

### 原因分析

1. **PD控制器参数不合适**
   - 原始参数：kp=10, kd=1 太小
   - 导致系统响应慢，阻尼不足，容易振荡

2. **关节阻尼太小**
   - 原始阻尼：damping="0.01" 太小
   - 无法有效抑制振荡

3. **初始状态未初始化**
   - 如果初始角度/速度不为0，会有初始振荡

4. **数值积分误差**
   - Euler积分器在小时间步下可能累积误差

### 解决方案

#### 1. 调整PD控制器参数

```python
# 对于质量2kg，惯性0.04的系统，建议：
joint_kp = 50.0  # 比例增益（增加响应速度）
joint_kd = 5.0   # 微分增益（增加阻尼）
```

**参数选择原则**：
- kp 太小 → 响应慢，稳态误差大
- kp 太大 → 超调，可能不稳定
- kd 太小 → 阻尼不足，容易振荡
- kd 太大 → 响应变慢，可能过阻尼

#### 2. 增加关节阻尼

```xml
<joint damping="0.5" ... />
```

阻尼的作用：
- 提供速度相关的阻力
- 抑制振荡
- 提高系统稳定性

#### 3. 初始化状态

```python
data.qpos[0] = 0.0
data.qvel[0] = 0.0
mujoco.mj_forward(model, data)  # 更新动力学
```

#### 4. 力矩限制

```python
target_tau = np.clip(target_tau, -50.0, 50.0)
```

防止力矩过大导致系统不稳定。

### PD控制器调参指南

#### 临界阻尼设计

对于二阶系统，临界阻尼比 ξ = 1 时：

```
kd = 2 * sqrt(kp * I)
```

其中 I 是转动惯量（0.04 kg·m²）

如果 kp = 50：
```
kd = 2 * sqrt(50 * 0.04) = 2 * sqrt(2) ≈ 2.83
```

#### 过阻尼设计（更稳定）

```
kd = 3 * sqrt(kp * I)  # ξ ≈ 1.5
```

如果 kp = 50：
```
kd = 3 * sqrt(2) ≈ 4.24
```

#### 欠阻尼设计（响应快但可能振荡）

```
kd = sqrt(kp * I)  # ξ ≈ 0.5
```

### 调试技巧

1. **观察状态输出**
   ```python
   print(f"角度: {data.qpos[0]:.4f}, 角速度: {data.qvel[0]:.4f}, 力矩: {data.actuator_force[0]:.4f}")
   ```

2. **逐步调整参数**
   - 先调 kp，找到合适的响应速度
   - 再调 kd，消除振荡

3. **检查力矩输出**
   - 如果力矩一直在饱和（±50），说明 kp 太大
   - 如果力矩很小但仍有抖动，说明需要增加 kd

4. **使用更好的积分器**
   ```xml
   <option integrator="RK4" />
   ```
   RK4比Euler更稳定，但计算量更大。
